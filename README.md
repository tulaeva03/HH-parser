# Аналитический комплекс мониторинга рынка вакансий (2026)

Программное решение для автоматизированного сбора и визуального анализа данных о вакансиях бизнес-аналитика с использованием API HeadHunter.

## Основной функционал

- Data Mining: Сбор вакансий по заданным ключевым запросам через API.
- Analytics Dashboard: Визуализация медианных зарплат, географии и востребованности навыков.
- Golden Stack: Определение наиболее высокооплачиваемых комбинаций навыков (Топ-15% рынка).
- Data Registry: Интерактивный реестр активных предложений с прямой адресацией на первоисточник.

## Требования

- Python 3.8 или выше.
- Активное интернет-соединение.

## Инструкция по эксплуатации

Для управления комплексом используется файл автоматизации run_project.bat.

1. Запуск: Выполните двойной клик по файлу run_project.bat.
2. Инициализация: Скрипт автоматически проверит зависимости и установит необходимые библиотеки Python.
3. Обработка данных:
    - Введите y для обновления базы данных через парсер.
    - Введите n для использования существующего локального кэша данных.
4. Доступ к интерфейсу: После запуска сервера откройте браузер по адресу:
   http://127.0.0.1:8050

## Структура проекта

- dashboard.py — Логика интерфейса и визуализации данных.
- hh_parser.py — Скрипт взаимодействия с внешним API.
- run_project.bat — Сценарий автоматизации запуска и контроля зависимостей.
- requirements.txt — Список необходимых модулей.
- hh_business_analyst_vacancies.json — Локальное хранилище данных.

## Завершение работы

Для прекращения работы сервера закройте окно командной строки. Повторный сбор данных рекомендуется проводить не чаще одного раза в неделю во избежание ограничений со стороны провайдера.

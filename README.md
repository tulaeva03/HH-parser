# Аналитический комплекс мониторинга рынка вакансий (2026)

Программное решение для автоматизированного сбора, очистки и визуального анализа данных о вакансиях в сфере бизнес- и системного анализа. Система взаимодействует с API HeadHunter и предоставляет инструменты для исследования рыночных трендов в реальном времени.

## Основной функционал

* **Data Mining и фильтрация**: Сбор данных через API с автоматическим отсеиванием нерелевантных позиций (недвижимость, риелторы, продажи, логистика) на основе встроенного списка стоп-слов.
* **Мультивалютный расчет**: Автоматическая конвертация зарплатных предложений из USD, EUR, KZT, BYN и UZS в рубли по актуальным курсам 2026 года для формирования сопоставимой аналитики.
* **Интерактивная визуализация**:
    * Динамические показатели средней и максимальной заработной платы.
    * Анализ востребованных навыков (Золотой стек).
    * Распределение вакансий по городам и ключевым работодателям.
    * Прогноз распределения зарплатного фонда.
    * Тепловая карта зависимости уровня дохода от комбинации ключевых компетенций.
* **Реестр вакансий**: Интерактивная таблица с поддержкой числовой сортировки по рублевому эквиваленту и прямыми ссылками на страницы вакансий.

## Технологический стек

* **Язык**: Python 3.11+ (поддерживается автоматическая установка через загрузчик).
* **Библиотеки**: Pandas (обработка данных), Plotly/Dash (построение интерфейса и графиков), Requests (взаимодействие с API), Dash Bootstrap Components (дизайн интерфейса).
* **Формат данных**: JSON и CSV (используются для хранения и передачи данных между модулем сбора и модулем визуализации).

## Инструкция по запуску

Для автоматизации развертывания и управления проектом используется файл диагностики и запуска run_project.bat.

### Шаг 1. Подготовка системы
1. **Распаковка архива**: Убедитесь, что все файлы извлечены в обычную папку. Запуск скриптов напрямую из ZIP-архива невозможен.
2. **Права доступа**: Для корректной работы установщика библиотек и создания виртуального окружения может потребоваться доступ к сети Интернет.

### Шаг 2. Запуск проекта
1. Запустите файл **run_project.bat** двойным кликом мыши. 
2. Скрипт автоматически выполнит следующие действия:
    * Проверит наличие Python в системе (в случае отсутствия предложит автоматическую установку).
    * Создаст изолированное виртуальное окружение (venv) для предотвращения конфликтов библиотек.
    * Установит все необходимые зависимости из requirements.txt.
3. **Выбор режима данных**:
    * Введите **y** и нажмите Enter, если требуется обновить базу данных (запуск hh_parser.py).
    * Нажмите **Enter** без ввода символов, если хотите использовать ранее загруженные данные.
4. **Работа с интерфейсом**: Дождитесь появления сообщения "Dash is running on [http://127.0.0.1:8050](http://127.0.0.1:8050)". После этого откройте любой современный браузер и перейдите по указанному адресу.

## Структура проекта

* **run_project.bat** — Центральный скрипт автоматизации. Выполняет диагностику среды, управление виртуальным окружением и запуск модулей.
* **dashboard.py** — Модуль визуализации. Выполняет обработку данных, финальную фильтрацию и построение веб-интерфейса.
* **hh_parser.py** — Модуль сбора данных. Осуществляет многопоточные запросы к API HH.ru, извлекает детальные описания вакансий и навыки.
* **hh_business_analyst_vacancies.csv / .json** — Локальные файлы базы данных, формируемые парсером.
* **requirements.txt** — Перечень библиотек, необходимых для работы программного комплекса.
* **video.mov** — Видео с демонстрацией запуска и работы.

## Логика обработки и очистки данных

1. **Многоуровневая фильтрация**: Система автоматически исключает вакансии, заголовки которых содержат ключевые слова, не относящиеся к аналитике (например: риелтор, водитель, оператор склада).
2. **Нормализация дохода**: Для вакансий, где указана только верхняя или нижняя граница зарплаты, система рассчитывает среднее значение. Все значения приводятся к рублевому эквиваленту.
3. **Обработка навыков**: Модуль аналитики очищает список ключевых навыков от дублей и пустых значений для корректного построения рейтинга компетенций.

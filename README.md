# Аналитический комплекс мониторинга рынка вакансий (2026)

Программное решение для автоматизированного сбора, очистки и визуального анализа данных о вакансиях в сфере бизнес- и системного анализа. Система использует API HeadHunter и обрабатывает данные в формате JSON.

## Основной функционал

* **Data Mining и фильтрация**: Сбор данных через API с автоматическим отсеиванием нерелевантных позиций (недвижимость, риелторы, продажи, логистика) на основе стоп-слов.
* **Мультивалютный расчет**: Конвертация зарплат из USD, EUR, KZT, BYN в рубли по актуальным курсам 2026 года для формирования единой аналитики.
* **Интерактивная визуализация**:
    * Динамические показатели средней и максимальной зарплаты.
    * Анализ востребованных навыков («Золотой стек»).
    * Распределение вакансий по городам и работодателям.
    * Прогноз изменения зарплатного фонда до конца 2026 года.
    * Тепловая карта (заработная плата и комбинации компетенций)
* **Реестр вакансий**: Таблица с поддержкой числовой сортировки по рублевому эквиваленту и прямыми ссылками на вакансии.

## Технологический стек

* **Язык**: Python 3.8+
* **Библиотеки**: Pandas (обработка JSON), Plotly/Dash (интерфейс), Requests (парсинг).
* **Формат данных**: JSON (основной формат хранения и обмена данными между парсером и дашбордом).

## Инструкция по запуску

Для управления проектом используется файл `run_project.bat`.

1.  **Запуск**: Выполните двойной клик по файлу `run_project.bat`.
2.  **Инициализация**: Система проверит наличие зависимостей из `requirements.txt`.
3.  **Обработка данных**:
    * Введите **n**, чтобы запустить дашборд на основе имеющегося файла `hh_business_analyst_vacancies.json`.
    * Введите **y**, чтобы запустить `hh_parser.py` для обновления базы данных.
4.  **Просмотр**: Интерфейс доступен в браузере по адресу: `http://127.0.0.1:8050`

## Структура проекта

* `dashboard.py` — Скрипт визуализации. Загружает `hh_business_analyst_vacancies.json`, выполняет финальную фильтрацию и строит графики.
* `hh_parser.py` — Скрипт сбора данных. Формирует JSON-файл, извлекая детали вакансий, навыки и параметры зарплат.
* `hh_business_analyst_vacancies.json` — Файл базы данных.
* `requirements.txt` — Список необходимых библиотек Python.

## Логика обработки данных

1.  **Очистка**: При загрузке JSON-файла система применяет фильтр релевантности. Исключаются позиции, содержащие в названии ключевые слова: *риелтор, брокер, курьер, продажи, маркетинг, тендер, кредитный, директор*.
2.  **Валюты**: Поля `salary_from` и `salary_to` умножаются на коэффициент соответствующей валюты (`currency`) перед вычислением среднего значения.
3.  **Сортировка**: В таблице вакансий используется скрытое числовое поле для корректного ранжирования зарплат от большего к меньшему.
